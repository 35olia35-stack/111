Privacy Policy

This Privacy Policy describes how eBay Listing Assistant handles user data.

Data Collection

eBay Listing Assistant does not collect, store, or sell personal data. The extension does not track users or use data for advertising purposes.

How the Extension Works

The extension processes listing data directly on the current eBay page to generate titles and descriptions and insert them into the listing form. This happens only when the user interacts with the extension.

Remote Processing

Some features may send listing-related data to a remote API in order to generate requested content (such as titles or descriptions). These requests do not include sensitive personal data and are used only to provide the functionality of the extension.

Local Storage

User preferences and interface state may be stored locally in the browser using Chrome storage. This data remains on the user's device and is not shared with third parties.

Data Sharing

The extension does not sell, share, or transfer user data to third parties.

Permissions Usage

The extension uses permissions only to access the current eBay page, extract listing data, and insert generated content as requested by the user.
